# Commit Emoji Reference

## Subject line — one emoji per commit, by type

| Type       | Emoji | When to use                            |
|------------|-------|----------------------------------------|
| `feat`     | ✨    | New feature or functionality           |
| `fix`      | 🐛    | Bug fix                                |
| `fix`      | 🚑️   | Critical hotfix                        |
| `refactor` | ♻️    | Code restructuring, no behavior change |
| `test`     | ✅    | Add or update tests                    |
| `docs`     | 📝    | Documentation changes                  |
| `style`    | 🎨    | Formatting, structure improvements     |
| `perf`     | ⚡️   | Performance improvement                |
| `chore`    | 🔧    | Config, tooling, maintenance           |
| `ci`       | 👷    | CI/CD changes                          |
| `build`    | 📦️   | Build system or dependencies           |
| `revert`   | ⏪️   | Revert a previous commit               |

## Body line emojis — any that fit

| Emoji | Meaning                            |
|-------|------------------------------------|
| 🔥    | Remove code or files               |
| ➕    | Add a dependency                   |
| ➖    | Remove a dependency                |
| ⬆️    | Upgrade dependency                 |
| ⬇️    | Downgrade dependency               |
| 📌    | Pin dependency version             |
| 🚚    | Move or rename files               |
| 🏷️    | Add or update types                |
| 💡    | Add comments                       |
| ⚰️    | Remove dead code                   |
| 🥅    | Catch errors                       |
| 🗃️    | Database changes                   |
| 🔊    | Add logs                           |
| 🔇    | Remove logs                        |
| 🙈    | Update .gitignore                  |
| 🩹    | Simple non-critical fix            |
| 👔    | Business logic                     |
| 🦺    | Validation code                    |
| 🧱    | Infrastructure                     |
| 🔒️   | Security fix                       |
| 🛂    | Auth/permissions                   |
| 🌱    | Seed files                         |
| 🔨    | Development scripts                |
| 🚨    | Fix linter warnings                |
| 💚    | Fix CI build                       |
| 🧪    | Add a failing test                 |
| 🩺    | Healthcheck                        |
| 🤡    | Mock things                        |
| 👽️   | Update due to external API changes |
| 🧵    | Threading/concurrency              |
| 💥    | Breaking change                    |
| 🚀    | Deploy                             |
| 💄    | UI and style                       |
| 🔐    | Secrets                            |
| 📈    | Analytics/tracking                 |
| 🌐    | Internationalization               |
| ✏️    | Fix typos                          |

Any other emoji that clearly describes the change is also valid.
